# Wisdom Graph

## Overview

The Wisdom Graph is Aletheia's knowledge representation layer. It is **not** a generic RAG corpus. It is a structured graph of concepts, traditions, claims, and counterclaims that preserves disagreements rather than collapsing them.

## Schema

Three node types:

### `Tradition`

```python
class Tradition(BaseModel):
    id: str            # e.g. "stoicism"
    name: str          # e.g. "Stoicism"
    category: Literal[
        "mysticism", "philosophy", "psychology",
        "science", "literature", "religion", "other"
    ]
    region: str | None
    period: str | None
    summary: str
```

### `Concept`

```python
class Concept(BaseModel):
    id: str                       # e.g. "ego"
    label: str                    # human-readable
    summary: str
    traditions: list[str]         # traditions that address this concept
    related_concepts: list[str]   # graph edges
    epistemic_status: EpistemicStatus  # usually PHILOSOPHICAL-VIEW
```

### `WisdomClaim`

```python
class WisdomClaim(BaseModel):
    id: str
    concept_id: str               # the concept this claim is about
    text: str                     # the claim itself
    tradition: str                # who makes the claim
    citation: SourceCitation      # MANDATORY: tradition, author, work, locator
    epistemic_status: EpistemicStatus
    counterclaims: list[str]      # IDs of opposing claims
```

## Seed data

The MVP ships with a seed graph at `src/aletheia/data/seed.jsonl` containing:

- **10 traditions**: Stoicism, Zen, Sufism, Taoism, Vedanta, Existentialism, Christian Mysticism, Kabbalah, Depth Psychology, Cognitive Science
- **16 concepts**: ego, desire, attachment, fear, suffering, freedom, identity, death, love, meaning, awareness, truth, compassion, control, self_deception, narrative
- **25 claims** distributed across traditions, with counterclaims linking opposing positions

### Example: preserved disagreement

The seed includes a clear pair of disagreeing claims:

- `stoic_dichotomy_of_control`: "Some things are within our power... suffering arises only when we conflate the two." (Epictetus, *Enchiridion* 1)
- `cs_unconscious_control`: "Much of human behavior is generated by unconscious processes and rationalized post hoc." (Wegner, *The Illusion of Conscious Will*)

These are linked via `counterclaims`. Aletheia never merges them into a single "balanced view." Both positions are presented, with their sources.

## Loading

```python
from aletheia.wisdom import WisdomGraph

# Load the bundled seed
graph = WisdomGraph.default()

# Or load from a custom JSONL
graph = WisdomGraph.from_jsonl("path/to/your_corpus.jsonl")
```

The JSONL format is one record per line:

```json
{"type": "tradition", "data": {...}}
{"type": "concept",   "data": {...}}
{"type": "claim",     "data": {...}}
```

Lines starting with `#` are comments and ignored.

## Retrieval

MVP retrieval is keyword-based with an overlap-coefficient score:

```python
from aletheia.wisdom import WisdomRetriever

retriever = WisdomRetriever(graph, top_k=3)
claims = retriever.retrieve("I am afraid of dying and want my life to matter")

# Retrieve with counterclaims (preserves disagreement)
claims_with_counters = retriever.retrieve_with_counters("death and mortality")
```

Vector-based retrieval (sqlite-vec / pgvector) is planned for v0.2. The retriever interface is designed to swap in cleanly.

## Adding your own corpus

1. Create a JSONL file following the format above.
2. Set `ALETHEIA_WISDOM_GRAPH_SEED_PATH` to its path.
3. Or load directly: `graph = WisdomGraph.from_jsonl("your_file.jsonl")`

### Sourcing rules

- Every `WisdomClaim` MUST have a `SourceCitation` with at least `tradition` set.
- When `work` is set, `locator` (page, chapter, verse) is strongly recommended.
- Fabricated quotations are forbidden. If you cannot verify a source, paraphrase and label the claim `[PHILOSOPHICAL-VIEW]`.
- The seed graph contains only real, verifiable sources.

## Disagreement preservation

The graph's defining commitment is that **disagreements between traditions are never collapsed**. When you add a claim, consider whether opposing positions exist in other traditions, and link them via `counterclaims`.

The graph never presents itself as having resolved a philosophical dispute. It presents the dispute, with sources, and lets the user think.

## Limitations in v0.1

- **Keyword retrieval only.** Vector retrieval is planned.
- **In-memory only.** Persistence to SQLite is planned.
- **English-only seed.** Multilingual expansion is planned.
- **No provenance tracking for edits.** A user-editable graph would need versioning.
